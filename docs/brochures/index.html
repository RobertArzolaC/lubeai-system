Cómo generar el PDF

  1. Abra el documento que va a compartir.
  2. Pulse Ctrl + P (Windows) o Cmd + P (Mac) y elija “Guardar como PDF”.
  3. Use tamaño A4, márgenes Ninguno y active Gráficos de fondo.
  4. Comparta el PDF o la carpeta brochures/ completa. Un HTML suelto, sin la carpeta assets/, se ve sin estilos.

Antes de enviarlo

  1. Verifique que el documento hable del perfil correcto y no de todos a la vez.
  2. Confirme que el contacto sea solutions@lubeai.tech y +51 993 373 231.
  3. No agregue canales, integraciones ni plazos que no estén aprobados en el README del kit.
